# Perpetuo

This repository is the home for everything built for **Perpetuo magazine** — the magazine's web app, plus internal tools and Claude Code skills used to run it.

## What's in here

- **[Poem Visualizer app](./APP.md)** — A Next.js app for visualizing poems. This currently lives at the root of the repo (it's the original project). See its README for setup and development instructions.
- **[`.claude/skills/`](./.claude/skills/README.md)** — Claude Code skills used for Perpetuo workflows (e.g. turning sponsorship call transcripts into proposals).

## Adding new projects

When adding a new piece of Perpetuo code (a new app, script, or tool), give it its own folder with its own README explaining what it is and how to use it, and add a link to it in the list above.
